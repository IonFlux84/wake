# Roles

Roles follow Ghost. Every account has exactly one.

| | Owner | Administrator | Editor | Author | Contributor |
|---|:-:|:-:|:-:|:-:|:-:|
| Write drafts | ✓ | ✓ | ✓ | ✓ | ✓ |
| Edit others' entries | ✓ | ✓ | ✓ | | |
| Publish own posts | ✓ | ✓ | ✓ | ✓ | |
| Publish any entry | ✓ | ✓ | ✓ | | |
| Delete entries | ✓ | ✓ | ✓ | own drafts | own drafts |
| See statistics | ✓ | ✓ | ✓ | ✓ | ✓ |
| Edit the consent banner | ✓ | ✓ | | | |
| Manage categories | ✓ | ✓ | | | |
| Manage the team and settings | ✓ | ✓ | | | |
| Tokens for assistants | ✓ | ✓ | ✓ | ✓ | without publishing |

Contributors only see their own entries in the lists. The site has exactly one
owner, who is created during setup.

Tokens for AI assistants never have more rights than the person who created
them; see [MCP server](mcp.md#tokens).
